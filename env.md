# Required Environment Variables

- `SUPABASE_URL`: The URL of your Supabase project.
- `SUPABASE_ANON_KEY`: The anon key for your Supabase project.
- `SUPABASE_SERVICE_ROLE_KEY`: The service role key for your Supabase project.
- `JWT_SECRET`: A secret for signing JWTs.
- `MAGIC_LINK_JWT_SECRET`: A secret for signing magic link JWTs.
- `SESSION_JWT_SECRET`: A secret for signing session JWTs.
- `APP_BASE_URL`: The base URL of your frontend application.
- `FRONTEND_AFTER_LOGIN`: The path to redirect to after a successful login.
- `SESSION_COOKIE_NAME`: The name of the session cookie.
- `SESSION_EXPIRES_MS`: The session expiration time in milliseconds.
- `SMTP_HOST`: The hostname of your SMTP server.
- `SMTP_PORT`: The port of your SMTP server.
- `SMTP_USER`: The username for your SMTP server.
- `SMTP_PASS`: The password for your SMTP server.
- `FEATURE_USER_ACCOUNTS`: Set to `true` to enable user accounts feature.
